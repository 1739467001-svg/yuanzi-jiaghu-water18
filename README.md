# 原子江湖 · AtomHub Living World

原子公社的可运行 3D 社区原型。白蓝斗笠侠客、青瓦茶楼、共创工坊、开源书院、石桥与比赛展示馆共同构成第一张地图。

## 启动

需要 Node.js 22.12+。

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。也可以双击 `启动原子江湖.command`。

```bash
npm test
npm run build
npm run preview
```

`dev` 和 `preview` 都包含本地聊天接口；只把 `dist` 放到静态主机不会提供聊天 API。当前监听回环地址，适合本地评审，尚不是公开部署方案。

## 浏览器验证

启动本地服务后执行 `npm run test:e2e`。默认使用已安装的 Google Chrome；自动检查桌面、390px 手机布局、作品深链接、记忆删除与 WebGL 降级，并将截图写入忽略版本管理的 `artifacts/`。

## 已实现

- Three.js 真实几何场景、可旋转缩放镜头、点击移动、建筑碰撞与过桥路径。
- 八位虚构 AI 侠客的本地活动状态机：前往建筑、歇脚、两两社交、记录公共见闻；私人交谈可打断活动。
- 原创 IP 参考的程序化角色：黑斗笠、白衣、蓝衣带、脸颊、佩剑；可改昵称与衣带颜色。
- 日夜切换、四套环境配色。主题切换目前只改变配色；建筑位置可在 `src/world/config.js` 编辑，未提供拖拽地图编辑器。
- 可进入的独立 3D 展厅，按筛选条件显示前八件展品；完整目录可访问两场比赛的全部 56 条记录。
- 赛事切换、赛道筛选、作品/作者搜索、高清海报、收藏、最近浏览、稳定的 `?work=赛事--slug` 分享链接。
- 本地资料检索向导；可选 OpenAI 兼容模型接口。
- 用户主动开启的兴趣记忆，按角色隔离，允许逐条或全部删除。删除会清除对话上下文并取消尚未完成的请求。
- 手机布局、键盘对话框焦点约束、无 WebGL 时的作品目录入口。

## 模型配置（可选）

将 `.env.example` 复制为 `.env.local`，填写模型服务地址、模型名和密钥，然后重启服务。不要把密钥放在 `VITE_` 变量或提交到 Git。

未配置时，界面明确显示“本地资料演示”，回答来自检索和预设话术。它不是已连接语言模型的自主智能体。配置后，私人对话可调用真实模型；NPC 间的日常社交仍是本地状态机演示。

接口设置 20 秒超时、最多 3 个并发，以及每次本地服务进程的请求数量上限。`ATOM_SESSION_LIMIT` 计数在进程重启时归零。生产系统需要持久预算和 token 计费。

## AI Town 的关系

上游：https://github.com/a16z-infra/ai-town

固定参考提交：`8e05997f2409275669c8344b84a51692e83f3f33`。

上游已克隆在 `references/ai-town`，不安装或运行其 Convex 服务。本版本是独立的 3D 表现层和本地体验原型，尚未接入 AI Town 的世界循环、联机和向量记忆。不能将本地八位角色表述为八个已经联网运行的语言模型 Agent。

`src/world/aiTownAdapter.js` 定义了上游平面坐标到三维坐标的转换和公开角色字段边界。接入规划、已发现的身份问题见 `docs/AI_TOWN_INTEGRATION.md`。

## 内容与品牌

- 品牌依据：根目录《原子公社对外介绍 v2.2(1).pptx》第 1、5—10、21 页。已读取原始文本；本轮未取得微信公众号正文，不将公众号搜索结果当成已核实来源。
- 五个价值观：个体至上、开放共享、务实求真、互助共赢、持续进化。
- 主理人“点灯人”对应迎新伙伴；开放共享对应书院；真实实践对应工坊；成果沉淀对应展馆。
- IP 欢迎图使用用户提供的原图；3D 模型为基于形象特征制作的几何原型，不是最终美术资产。
- 官方 Logo 来自 `Logo/原子公社logo/黑字.png`，仅裁切透明留白并等比缩小。
- FunSkills 38 条，黑客松 18 条。正式名单口径、成果真实性和公开使用范围仍需运营核对。
- 导入脚本白名单保留公开展示字段，不迁移微信号及群二维码。

更新现有来源数据后，运行 `npm run content:import`。本原型不修改两个历史展示站，也不向其服务器提交互动数据。

## 结构

```
src/App.jsx                 页面、展馆、聊天、记忆与收藏
src/world/World.jsx         Three.js 场景、交互与生命周期
src/world/models.js         角色、建筑、桥梁、树木与原子雕塑
src/world/config.js         建筑布局、角色设定、主题
src/world/engine.js         本地寻路、日程与社交状态机
src/world/aiTownAdapter.js  上游坐标与公开字段适配边界
src/data/editions.json      56 条来源作品
server/chat.mjs             本地资料检索与可选模型代理
scripts/import-content.mjs 来源数据导入
public/                    已复制的必要品牌与作品素材
tests/                     路径、状态机、内容、记忆及坐标测试
```
