# 原子江湖 · AtomHub Living World

原子公社的可运行 3D 社区原型。白蓝斗笠侠客、青瓦茶楼、共创工坊、开源书院、石桥与比赛展示馆共同构成第一张地图。

## 在线演示与 GitHub

- 仓库：https://github.com/1739467001-svg/Atomic-Jianghu
- 在线 3D 演示：https://1739467001-svg.github.io/Atomic-Jianghu/

推送 main 后，GitHub Actions 自动测试、构建并部署 GitHub Pages。线上使用浏览器内的资料检索与演示对话，不提供模型代理或云端数据存储。作品、3D 小镇、收藏与授权记忆均可使用。

手动构建同样的静态版：`VITE_BASE_PATH=/Atomic-Jianghu/ VITE_STATIC_DEMO=true npm run build`。部署产物是 dist；本地开发不设这两个变量即可继续使用 Vite 提供的 API。

## 启动

需要 Node.js 22.12+。

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。也可以双击 `启动原子江湖.command`。

```bash
npm test
npm run validate:world
npm run build
npm run preview
```

`dev` 和 `preview` 都包含本地聊天接口；只把 `dist` 放到静态主机不会提供聊天 API。当前监听回环地址，适合本地评审，尚不是公开部署方案。

## 浏览器验证

启动本地服务后执行 `npm run test:e2e`。默认使用已安装的 Google Chrome；自动检查桌面、390px 手机布局、作品深链接、记忆删除与 WebGL 降级，并将截图写入忽略版本管理的 `artifacts/`。

## 已实现

- Three.js 真实几何场景、可旋转缩放镜头、点击移动、建筑碰撞与过桥路径。
- 八位虚构 AI 侠客的本地活动状态机：时辰节律（清晨茶楼、午后看展、入夜展会、深夜早歇）、前往建筑、歇脚、两两社交（头顶浮现话题气泡）、记录公共见闻；私人交谈可打断活动。
- 原创 IP 参考的程序化角色：黑斗笠、白衣、蓝衣带、脸颊、佩剑；可改昵称与衣带颜色。
- 日夜切换、四套环境配色。夜间为“繁星之夜”品牌线：深海蓝界面 + 繁星金点缀、窗外星空月亮与流萤、展馆星空穹顶；主题切换只改变配色，建筑位置可在 `src/world/config.js` 编辑，未提供拖拽地图编辑器。
- 可进入的独立 3D 展厅：房间固定的共享展陈（当前 FunSkills 38 条、5 个展区），展馆内可用“公共展区”翻页器切换展区（全房间一致，超出展位的作品通过编号展区展示）；展位带赛道色标识；完整目录可访问繁星之夜 38 条、数智星光展 18 条与星火计划介绍（作品整理中，暂不生成作品清单）。
- 赛事切换、赛道筛选、作品/作者搜索、高清海报、收藏、最近浏览、稳定的 `?work=赛事--slug` 分享链接。
- AI 观展闭环：AI 侠客按时辰与兴趣前往展会，按 计划→移动→观察→生成 状态机完成观展，生成不超过 60 字、标明“观感”的观点（只引用结构化事实，不编造奖项）；作品撤回或离开共享展位即刻取消任务；同一角色对同一内容版本有冷却，全局观感生成有会话预算；观展记忆会进入后续社交话题。展馆内可看到观展者站位、朝向与观感气泡，点击其名帖打开对应作品。
- 结构化优先的展馆导览（知微）：先回答赛事结构、赛道与作品事实，引用卡片可“带我去”走到展位，未上展作品提供“直接阅读”；奖项与结果未收录时明确说明。另有本地资料检索向导与可选 OpenAI 兼容模型接口。
- 用户主动开启的兴趣记忆，按角色隔离；带保留期限（默认 30 天，到期自动停止参与回忆但不静默删除），手札中显示剩余天数；关闭记忆时可选择“保留已有记录”或“同时删除”。删除会清除对话上下文并取消尚未完成的请求。
- 手机布局、键盘对话框焦点约束、无 WebGL 时的作品目录入口。
- 游历手札“侠客见闻”：AI 侠客的公开行程与社交时间线（不含私人聊天内容）。
- 开发态运营后台 `/admin.html`（仅 `npm run dev`/`preview`）：目录（草稿/送审/发布/撤回）、导入任务（差异预览→应用，微信号与二维码剔除并计数）、发布版本（快照与回滚）、审计流水；覆盖、版本与审计持久化在 `data/ops-state.json`，重启不丢失；导入写 `editions.json` 并复制媒体，开发态内容服务随后热加载。
- 联机演示（同浏览器多标签）：BroadcastChannel 组成房间，两个标签页互相看到真人化身移动，名帖与衣带色实时同步，加入/离开进入“江湖此刻”。
- 真人一对一私聊：点击真人名帖发起邀请，对方接受后开始私人会话；支持婉拒（含 30 秒冷却）、忙碌自动婉拒、30 秒邀请超时、结束交谈与屏蔽；正文只存在于双方面板，公开动态只记录“开始私下交流”的事实，世界快照与调试接口不出现正文（有测试保证）。账号体系与服务端权威尚未接入。
- 性能：`npm run bench` 固定路线基准（首交互、帧率分位、绘制调用）；运行时可开“性能指示器”查看帧率；连续 3 秒低于 30 FPS 自动降级（阴影→粒子→像素比），`?degrade=1` 可预览降级观感。基线见 docs/PERFORMANCE.md。

## 模型配置（可选）

将 `.env.example` 复制为 `.env.local`，填写模型服务地址、模型名和密钥，然后重启服务。不要把密钥放在 `VITE_` 变量或提交到 Git。

未配置时，界面明确显示“本地资料演示”，回答来自检索和预设话术。它不是已连接语言模型的自主智能体。配置后，私人对话可调用真实模型；NPC 间的日常社交仍是本地状态机演示。

接口设置 20 秒超时、最多 3 个并发，以及每次本地服务进程的请求数量上限。`ATOM_SESSION_LIMIT` 计数在进程重启时归零。生产系统需要持久预算和 token 计费。

## AI Town 的关系

上游：https://github.com/a16z-infra/ai-town

固定参考提交：`8e05997f2409275669c8344b84a51692e83f3f33`。

上游已克隆在 `references/ai-town`，不安装或运行其 Convex 服务。本版本是独立的 3D 表现层和本地体验原型，尚未接入 AI Town 的世界循环、联机和向量记忆。不能将本地八位角色表述为八个已经联网运行的语言模型 Agent。

`src/world/aiTownAdapter.js` 定义了上游平面坐标到三维坐标的转换和公开角色字段边界。接入规划、已发现的身份问题见 `docs/AI_TOWN_INTEGRATION.md`。

## 内容与品牌

- 品牌依据：根目录《原子公社对外介绍 v2.2(1).pptx》第 1、5—10、21 页。已读取原始文本；本轮未取得微信公众号正文，不将公众号搜索结果当成已核实来源。
- 五个价值观：个体至上、开放共享、务实求真、互助共赢、持续进化。
- 主理人“点灯人”对应迎新伙伴；开放共享对应书院；真实实践对应工坊；成果沉淀对应展馆。
- IP 欢迎图使用用户提供的原图；3D 模型为基于形象特征制作的几何原型，不是最终美术资产。
- 账号（联机产品形态）：注册/登录/登出，会话为 HttpOnly Cookie；登录后收藏与记忆同步到账号（按 userId 隔离、版本冲突保护、30 天 TTL），并提供本机→云端迁移选择；顶栏区分“访客/成员”。
- 运营后台鉴权：/api/admin 要求运营角色（未登录 401、无权限 403），后台内置登录与开发态提权；操作进审计流水。
- 用量账本：模型调用按 requestId 去重、预留后结算；每日预算 80% 降级、100% 暂停新调用；/api/usage 可查（ATOM_DAILY_BUDGET 配置）。
- 官方 Logo 来自 `Logo/原子公社logo/{黑字,白字}.png`：开机画面与关于面板使用裁切后的字标（浅色用黑字版、夜间用白字版），原子轨道图形另有单独裁切件；仅裁切透明留白并等比缩小，未重绘。
- FunSkills 38 条，黑客松 18 条，星火计划为介绍稿（无作品清单）。正式名单口径、成果真实性和公开使用范围仍需运营核对。赛道色与作品亮点来自两个来源展示站的公开数据。
- 导入脚本白名单保留公开展示字段，不迁移微信号及群二维码。

更新现有来源数据后，运行 `npm run content:import`。本原型不修改两个历史展示站，也不向其服务器提交互动数据。

## 内容与共享展陈

赛事、赛道与作品统一走 `src/content/catalog.js`：公开读取只返回 `publicationStatus` 为“已发布”的内容，草稿与已撤回不进入任何入口。3D 展厅、阅读目录、演示导览和内容接口读同一份数据。

3D 展厅展示房间固定的共享展陈展区 1（`src/content/exhibition.js`，当前为 FunSkills 38 条、5 个展区）；阅读面板的个人筛选只改变面板列表，用“展陈中”标记与展区编号区分。接口失败时前端降级到内置快照并提示，作品阅读不中断。详见 `docs/CONTENT_SERVICE.md`。
